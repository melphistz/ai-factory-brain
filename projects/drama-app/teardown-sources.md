## ⚠️ แต่ละ link = ทั้งเรื่อง (07-10 Mirko แจ้ง)
1 link = หลายตอนสั้นรวมยิงยาวจนจบ (ไม่ใช่ EP1 เดียว) · filesize 720p = 300-500MB/ไฟล์ = **~30-60 นาที/เรื่อง** (ประเมินจาก filesize; duration จาก extractor เชื่อไม่ได้ ต้อง ffprobe ตอนโหลดจริง)
- **ข้อดี:** ได้ arc เต็มทั้งเรื่อง (เปิด→humiliation→reveal→จบ) = เห็นลำดับการเล่าครบ ตรงเป้า
- **เป้าลดเหลือ 3-5 เรื่องพอ** (ทั้งเรื่อง = ข้อมูลเยอะ ไม่ต้อง 8-10) — เริ่ม 2-3 เรื่องกลุ่ม A ก่อน
- **pipeline ปรับสำหรับไฟล์ยาว:**
  1. `pip install imageio-ffmpeg` → yt-dlp โหลด 720p (1 เรื่อง)
  2. whisper ASR เต็มเรื่อง (ได้ transcript + timestamp ทุกตอน)
  3. ffmpeg scene-change detect + transcript timestamp → หั่นเป็นตอนย่อย (มักมี title card/beat คั่น)
  4. contact sheet **หลายแผ่นต่อเรื่อง** (5×6 ต่อ ~2-3 นาที ไม่ใช่ 30 frame ทั้งเรื่อง = หยาบไป)
  5. `teardown-analyst` (Sonnet+high, fan-out ต่อตอน/ต่อเรื่อง) แกะ **ลำดับการเล่า** ต่อตอน + arc ทั้งเรื่อง
  6. synthesis (Opus 4.8+ultracode) รวม pattern → feed เข้าสูตรแนว (ชั้น 3)
