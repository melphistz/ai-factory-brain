## A. Cinematography Bible (กฎที่ใช้ทุกช็อต)

### 1. ความสูงกล้อง = ระดับสายตาแมว (20–30 ซม.) ตลอดเรื่อง
- กล้องไม่เคยขึ้นสูงกว่าแมว → โลกของคนอยู่เหนือเฟรมเสมอ ซอมบี้ = ป่าขา
- ประหยัด AI: ไม่ต้องเจนหน้าซอมบี้ ไม่มีปัญหาหน้าเพี้ยน

### 2. Screen direction = ตัวตนของแม่
- **ก่อนเฉลย (S01–S15): แม่เดิน ขวา→ซ้าย** สวนฝูงที่เดิน ซ้าย→ขวา → เห็นแต่ซีกหูส้ม (ซีกปกติ) ซีกหูดำหันออกจากกล้องเสมอ
- **หลังเฉลย (S16–): แม่หันกลับ เดิน ซ้าย→ขวา ไปกับฝูง** → ซีกหูดำหันเข้ากล้องเป็นครั้งแรก
- เปลี่ยนทิศ = เปลี่ยนตัวตน: จาก "ทวนกระแสความตาย" → "เป็นส่วนหนึ่งของมัน"
- ⚠️ เช็คกับ sheet: ทิศนี้ตั้งบนสมมติฐานว่าหูดำคือหูขวาของแม่ (ตาม front view) ถ้า AI กลับลาย ให้กลับทิศตาม — กฎจริงคือ "ซีกหูดำห้ามเข้ากล้องก่อน S14"

### 3. กฎหน้า
- **หน้าแม่เต็มๆ ตรงๆ ครั้งแรก = S24** ก่อนหน้านั้นเห็นได้แค่: ข้างหลัง · เงาดำย้อนแสง · บางส่วน (ปาก เท้า หาง) · ด้านข้างซีกหูส้ม · ผ่านเงาสะท้อน (S14–15)
- **หน้าซอมบี้ = ครั้งเดียว (S18)** ตอนก้มลงมาอยู่ระดับแมว · ละลายโฟกัส ไม่คมชัด

### 4. Lens plan
| เลนส์ | ใช้กับ | ความรู้สึก |
|---|---|---|
| 24mm wide ต่ำ | เดินในฝูง (S02, S16, S17) | ขาซอมบี้ใหญ่ทะมึน โลกกว้างเกินตัว |
| 35mm | establishing ระดับพื้น (S04, S06, S07, S13, S18, S20) | เป็นกลาง เห็นพื้นที่ |
| 50mm | medium / POV (S03, S08, S12, S14, S21, S22) | ใกล้สายตาจริง |
| 85–100mm | CU ลูก, เงาสะท้อน, กระจก (S05, S09, S15, S19, S23–S26) | แยกตัวละครออกจากโลก ชัดตื้น |
| 100mm macro | คาบคอ, แอ่งน้ำ (S01, S10, S11) | ฟัน ขน ไอหายใจ ใกล้เกินสบาย |

### 5. Movement grammar — คู่ตรงข้าม S02 ↔ S17
- **S02 = Parallax + Dirty frame:** แม่เดินสวนฝูง → ขาใกล้กล้องพุ่งผ่านเร็ว ขาไกลคลาน → โลกวุ่นวาย แม่ฝืนกระแส
- **S17 = Locked-on:** แม่เดินไปกับฝูงด้วยความเร็วเท่ากัน → ขารอบตัว**แทบนิ่งในเฟรม** มีแค่ตึกฉากหลังที่ไหล → แม่กลายเป็นส่วนหนึ่งของฝูงแล้ว (ภาพเล่าแทนคำพูด)
- **Static = อันตราย / การตัดสินใจ** (ฉากหนู, ฉากคาบ, ซอมบี้ดม, ฉากเงาสะท้อน)
- **Push-in ใช้ 2 ครั้งเป็นคู่หัว-ท้าย**: S10 (ปากบนคอลูก) ↔ S26 (กระจกระหว่างแม่-ลูก) — จุดเริ่มกับจุดจบของ "การคาบ"
- **ไม่มี handheld shake, ไม่มี crane/drone, ไม่มี orbit, ไม่มี zoom**

### 6. เทคนิคเด่น — ใช้ครั้งเดียวในเรื่อง
| เทคนิค | ช็อตเดียว | เหตุผล |
|---|---|---|
| Rack focus | S14 | ส่งความสนใจจากตัวจริง → ความจริงในเงา |
| Reflections (เฉลย) | S14–S15 | เห็นซีกที่ซ่อนไว้โดยกล้องไม่ต้องหัน |
| Match cut | S19 → S20 | ไอหายใจลูก → กระจกรถที่ฝ้า = "รถหายใจ" |
| Silhouette (สะอาด) | S08 | แม่เป็นรูปทรง ไม่ใช่หน้า |
| Frame within frame | S24 | ช่องกระจกตีกรอบหน้าแม่ครั้งแรก |
| Locked-on | S17 | แม่กลืนกับฝูง |
| ❌ Dolly zoom | ไม่ใช้ | ตามหลัก Melies ใช้กับ "ตัวละครตระหนักรู้" แต่แมวในเรื่องไม่ตระหนักอะไรแบบคน + AI ทำไม่นิ่ง → ขัดสไตล์ Flow |

| Seq | แสง/สี |

### 8. Motif: ไอหายใจ = มาตรวัดชีวิต
| ช็อต | ไอหายใจ |
|---|---|
| S02 | ไม่มีใครมีไอหายใจเลย (ทั้งแม่และซอมบี้) — คนดูไม่รู้ตัว |
| S07 | ไอแรกในเรื่อง ลอยออกจากใต้รถเข็น = ชีวิตปรากฏก่อนตัว |
| S12 | ไอของลูกอยู่หน้าเฟรม จมูกแม่ไม่มี |
| S19 | ลูกตัวอ่อนเงียบในปากแม่ (transport response) ไอหายใจยังออกเบาๆ · ซอมบี้จากไป → ลมหายใจก้อนใหญ่ → **match cut** |
| S20 | รถคันเดียวที่กระจกฝ้า = รถที่ "หายใจ" |
| S25 | สองหน้าคนละฝั่งกระจก ฝ้าฝั่งเดียว |
| S26 | วงฝ้าบนกระจกบังแม่ที่เดินจากไป |
| S28 | ลูกอยู่ในป่าขา — **ไอหายใจเดียวในฝูง** |

### 9. Sound (diegetic ล้วน ไม่มีดนตรี)
เท้าลาก · ลม · น้ำหยด · เสียงลูกร้องไกลๆ · **S10–S11 เสียงหายหมด** · S14 นกร้องตัวแรกตอนแดดออก · S19→S20 เสียงพ่นลมหายใจต่อเนื่องข้าม cut · **S28 เสียงลูกร้องเรียกแม่ = เสียงเดียวกับ S02** · S29 เท้าลากทั้งฝูงหยุดพร้อมกัน → เงียบสนิท · S30 ตัดดำกลางความเงียบ

### 10. Style lock
painterly stylized 3D แบบ Flow · ขนเป็นฝีแปรง · แมวทำตัวเป็นแมวจริง ไม่มีสีหน้าแบบคน ไม่ร้องไห้ ไม่ยิ้ม · ไม่มีตัวหนังสือ ไม่มีป้ายอ่านออก
