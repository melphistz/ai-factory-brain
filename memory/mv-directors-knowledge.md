# ผู้กำกับ MV ดราม่า/เล่าเรื่อง — ความรู้สำหรับอ้างอิง

> สรุปจากการค้นเว็บ (มิ.ย. 2026) — ใช้คู่กับ [[director-styles-knowledge]] และ [[seedance-knowledge]]
> โฟกัส: MV ที่ "เล่าเรื่อง/ดราม่าเหมือนหนังสั้น" ไม่ใช่ MV เต้น/perform เฉยๆ

## 🇹🇭 ไทย

**ข้อสังเกตสำคัญ:** วงการไทยคนที่เก่งเล่าเรื่องมักเป็น **ผู้กำกับหนัง/โฆษณาที่ข้ามมาทำ MV** มากกว่าจะมี "ผู้กำกับ MV อาชีพ" ที่บันทึกชื่อชัดบนเว็บ — เครดิตผู้กำกับ MV ไทยมัก under-documented (เว็บส่วนใหญ่พูดถึงตัว MV/นางเอก MV มากกว่าคนกำกับ)

| ผู้กำกับ | จุดเด่น |
|---------|---------|
| **เต๋อ นวพล ธำรงรัตนฤทธิ์** | เล่าเรื่องใกล้ตัว มินิมอล อารมณ์ขันเศร้าๆ ใช้ text overlay + long take (รายละเอียด MV ด้านล่าง) |
| **เป็นเอก รัตนเรือง** | มาจากสายโฆษณา (ฟิล์มแฟ็กตอรี่) ภาพซีเนมาติกจัด อารมณ์เท่ๆ เหงาๆ |
| **คงเดช จาตุรันต์รัศมี** | อินดี้ นักเล่าเรื่อง บทคม ทำทั้งหนัง โฆษณา เพลงประกอบ |
| **บรรจง ปิสัญธนะกูล (โต้ง)** | นักเล่าเรื่องสายป็อป/สยอง คุมอารมณ์คนดูเก่ง |

**genre เด่นของไทย: "MV ปวดตับ"** — มิวสิควิดีโอดราม่ายาวเหมือนหนังสั้น (เพลงอกหัก สตริง/ลูกทุ่ง) เน้นพล็อตหักมุมเรียกน้ำตา เป็นเอกลักษณ์เฉพาะของวงการเพลงไทย

### เจาะลึก: MV ที่เต๋อ นวพล กำกับ (มีแค่ ~4 ชิ้น)
เขาทำ MV น้อยมาก เพราะรู้สึกว่ารูปแบบ MV จำกัด (มีเนื้อร้อง/ทำนอง/โครงเรื่องคุมไว้ครึ่งหนึ่งแล้ว + ต้องจบใน 3–5 นาที) ต่างจากโฆษณาที่ปรับจังหวะเองได้ เขาชอบงานที่มาจาก "Original Screenplay" ของตัวเอง
1. **SLUR** — *"อุคริ จุ๊บุ๊ หุหุ (Noob!)"*
2. **Gig Mueang Phraeo (กิ๊ก เมืองแพร่)** — *"ฉันผิดที่คิดว่าเรารักกัน"*
3. **Greasy Cafe** — *"หมุน"*
4. **Stamp Apisit (แสตมป์ อภิวัชร์)** — *"นักเลงคีย์บอร์ด"* (เสียดสีสังคม เล่าเรื่องเด่น)

## เชื่อมกับการทำวิดีโอ AI
เวลาจะทำ MV ดราม่าด้วย Seedance ลองหยิบลายเซ็นจากตารางไปใส่ช่อง Style/Camera เช่น:
- อยากเหงาๆ ขาวดำ → "Anton Corbijn style, black and white, intimate, poetic"
- อยากเซอร์เรียลมีนัยสังคม → "Hiro Murai style, surreal, long take, dreamlike"
- อยากดราม่าใกล้ตัวแบบไทยอินดี้ → "minimalist observer, sunlit, white space, analog (Nawapol style)"
(ดูสไตล์เต็มใน [[director-styles-knowledge]])
