# การเขียนเนื้อเพลงไทย — หลักสัมผัสและความไพเราะ

> เก็บจากการค้นเว็บ 2026-07-05 หลังผู้ใช้ติเนื้อเพลงร่างแรกของ [[kae-wan-nee-project]] ว่า "ไม่มีความสวยงามของสัมผัสภาษาไทยเลย"

## โครงสัมผัสพื้นฐาน
- **สัมผัสนอก** (บังคับในกลอน, ทำให้เพลง "ลื่นหู") = สัมผัสสระ**ระหว่างวรรค** — ตำแหน่งคลาสสิกเพลงไทย: คำท้ายวรรค → รับด้วยคำกลางๆ หรือท้ายของวรรคถัดไป
- **สัมผัสใน** (ไม่บังคับ แต่เพิ่มความไพเราะ) = คล้องกันภายในวรรคเดียว มีทั้งสัมผัสสระ (เสียงสระ+ตัวสะกดเดียวกัน) และสัมผัสพยัญชนะ/อักษร (เสียงพยัญชนะต้นเดียวกัน)

## 6 ประเภทสัมผัส — เรียงตาม "ความเสถียร" (Puntaiji)
| ประเภท | ตัวอย่าง | ความรู้สึก |
|---|---|---|
| สมบูรณ์ (perfect) | ฉัน–วัน | นิ่ง สมบูรณ์ ปิดประโยค |
| ใกล้เคียง (near) | ฉัน–ทำ | เกือบนิ่ง |
| แบบขยาย | ฟ้า–ดาว | เคลื่อน |
| แบบลด | ความ–ตา | ตึง ชวนไปต่อ |
| ไม่พ้อง (imperfect) | รัก–ฉัน | ลอย |
| พ้องตัวสะกด | วัด–โหวต | เสถียรน้อยสุด |
→ ใช้เป็นเครื่องมืออารมณ์: ท่อนที่อยาก "จบสวย" ใช้สมบูรณ์ · ท่อนที่อยากค้าง/ดึงไปต่อ ใช้แบบลด/ไม่พ้อง

## Rhyme scheme ระดับท่อน
- **เสถียร**: `aabb` (คู่ต่อเนื่อง) · `abab` (สลับ — เน้นวรรคสี่) · `xaxa` (คลี่คลายตอนท้าย)
- **ไม่เสถียร**: `abba` (ค้าง อยากไปต่อ) · `xaax`
- เคสจริง: "ก้อนหินก้อนนั้น" ใช้ abab ใน Verse (ชัดเจน) + แบบไม่เสถียรใน Chorus (ปั่นอารมณ์)

## วรรณยุกต์ vs เมโลดี้ (verycatsound) — ปัญหา "ข่มขืนเมโลดี้"
คำไทยมีทิศเสียงในตัว ถ้าโน้ตสวนทางจะร้องเพี้ยน/ฟังฝืน:
- **สามัญ** = อิสระสุด · **เอก** = ต่ำ เข้ากับเมโลดี้ขาลง · **โท** = สูงแล้วทิ้งลง เหมาะขาขึ้นแล้วลง · **ตรี** = สูงสุด ต้องโน้ตขึ้น · **จัตวา** = ต้องมีเอื้อนขึ้นท้าย
- ใช้จริงกับ Suno: คุมทำนองตรงๆ ไม่ได้ แต่เลือกคำ "เสียงเปิด/สามัญ" ที่ท้ายวรรคฮุกจะปลอดภัยกว่า คำตรี/จัตวาท้ายวรรคเสี่ยงเพี้ยน

## กฎมืออาชีพ (riddimer/vibedio/thematter)
1. ⭐ **ความหมายชนะสัมผัส** — ถ้าต้องเลือกระหว่างคำสัมผัสสวยแต่สื่อไม่ตรง กับคำไม่สัมผัสแต่ตรงอารมณ์ → เอาอย่างหลัง
2. สัมผัส "พอดี" ไม่ใช่ยัดทุกวรรค — เยอะเกิน = กลอนแปด ไม่ใช่เพลง
3. สัมผัสต้องสอดคล้องทำนอง/จังหวะหายใจของประโยคร้อง (ร้องแล้ว "สนุกปาก")
4. เขียนตรงเป้า สื่อความชัด — ไม่ใช่โชว์ฉันทลักษณ์แบบตำรา
5. จำนวนพยางค์ต่อวรรคควรใกล้เคียงกันในท่อนเดียวกัน (ร้องลง beat เดียวกัน)

## สไตล์ fellow fellow (ที่เราอ้างอิง)
ภาษาพูดเรียบง่าย มุมมองส่วนตัว เล่าเรื่องใกล้ตัว ("อย่าใช้ความเงียบมาคุยกัน", "ไม่เปลี่ยนเลย") — สัมผัสมีแต่ไม่แน่น hook ซ้ำชื่อเพลง ปลายวรรคมักลงคำเปิดเบาๆ (เธอ/เรา/ใจ)
