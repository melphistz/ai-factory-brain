# Vertical Drama Basics — จากชุดสอน Dramy.ai (เก็บ 2026-07-07)

> ต้นทาง: PDF 4 ไฟล์ใน `D:\Downloads\Documents\` (L01 บทไอเดีย · L02 บทสคริปต์ · L03 Keyword พื้นฐาน · Starter_Pack บทฮุก) — **Dramy.ai = ผู้เล่นไทย niche เดียวกับ [[smartaihub-drama-series]]** (สอน+ทำเครื่องมือละครแนวตั้ง AI) · เกี่ยว: [[drama-app-fable-ultracode-retrospective]]
> ระดับความลึก = เบสิกกว่าคลังเรา ([[seedance-knowledge]] · [[storyboard-knowledge]]) — เก็บเฉพาะส่วนที่เราไม่มี: **โครงเรื่อง/ตอนสายละคร**

## Format ละครแนวตั้ง (นิยามของวงการ)
- ตอนละ **60–120 วิ** (ไอเดียเริ่มที่ 30–60 วิ) · 9:16 · คนดูตัดสินใจไม่กี่วิแรกว่าจะดูต่อหรือเลื่อนผ่าน
- flow ผลิต: idea → script → storyboard → AI image → AI video → edit → publish (ตรง pipeline เรา)

## กติกาไอเดียให้ "ทำได้จริงด้วย AI" (ใช้ใน onboarding/story generator)
- ตัวละครหลัก **≤ 3 คน** · สถานที่หลัก **≤ 2 แห่ง** · ตอนสั้น 30–60 วิ
- เลี่ยงไอเดียกว้าง ("เรื่องรัก", "คนอกหัก") → ต้องเป็น **"สถานการณ์" ที่เห็นภาพชัด** เห็นภาพเร็ว ฉากไม่ซับซ้อน มีปมให้ตามต่อ
- เช็กก่อนเริ่ม: ชื่อเรื่อง / ตัวละครหลัก / สถานที่หลัก / ความขัดแย้ง / จุดขาย / Hook

## ⭐ โครงตอน 5 ช่วง (ทุกตอน)
`Hook (จุดเปิดที่ดึงคนดู) → Setup (ปูสถานการณ์) → Conflict (ปัญหาหลัก) → Twist (จุดเปลี่ยน) → Cliffhanger (จบค้างให้ตามต่อ)`
- **Cliffhanger บังคับทุกตอน** = กลไกหลักของซีรีส์แนวตั้ง (สังเกต: แผนรายตอนใน smartaihub ก็ปิดตอนด้วย hook ค้างแบบเดียวกัน)
- สคริปต์เต็มต่อตอน ควรมี: ช่วงเวลา / ภาพ / เสียง+บทพูด / อารมณ์ตัวละคร / หมายเหตุการสร้าง → ต่อยอดเป็น shot list/storyboard ได้ทันที

## ⭐ Hook 4 ประเภท (สายละคร — คู่กับ hook สาย ad ใน [[ads-50-teardown-ai-video-bootcamp]])
1. **Visual Hook** — ดึงด้วยภาพ: อุบัติเหตุ, ภาพผิดปกติ/ขัดสถานการณ์, คนแต่งตัวไม่เข้ากับที่, ภาพอันตรายชวนตกใจ
2. **Emotional Hook** — ทำให้ "รู้สึก" ทันที: สงสาร, โกรธแทน, เจ็บแทน, เอาใจช่วย (นางเอกโดนตบ, ถูกไล่ออกจากบ้าน)
3. **Curiosity Hook** — ให้ข้อมูล "บางส่วน" ไม่เฉลย: ความลับ, ปริศนา, ข้อความแปลกๆ → คนดูรู้สึก "ถ้าไม่ดูต่อจะไม่เข้าใจ"
4. **Conflict Hook** — เปิดด้วยความขัดแย้ง: กล่าวหา, ดูถูก, เผชิญหน้า, ความสัมพันธ์ต้องห้าม → อยากรู้ใครถูก/ใครแพ้/เรื่องจะจบยังไง
- **เกณฑ์เลือก:** ห้ามเลือกเพราะแรงอย่างเดียว — ต้องเข้ากับโทนเรื่อง + **เนื้อหลังเรื่องต้องพาไปหาคำตอบของ hook นั้นจริง** (เปิดด้วยความลับ = เรื่องต้องไล่หาคำตอบ, เปิดด้วยความขัดแย้ง = เรื่องต้องพาสู่ผลของมัน)
- แก่น: hook ที่ดีไม่ใช่แค่หยุดนิ้ว แต่ทำให้รู้สึก **"ฉันอยากรู้ต่อว่าเรื่องนี้จะไปทางไหน"**

## Shot craft ที่ยืนยันของเดิม (ไม่ต้องเก็บซ้ำ — อยู่ใน vault แล้ว)
- shot size 4 ระดับ + **medium shot = ระยะ default ของซีรีส์** (สมดุลอารมณ์+ภาษากาย) — สอดคล้อง pitfall เรา "full-body เสี่ยง artifact, เลือก medium/close ปลอดภัยกว่า"
- แบบฝึกดี: แตก 1 ซีนเป็น 4 ขนาดภาพ (ไกล=บอกสถานที่ → กลาง=ทำอะไร → ใกล้=รายละเอียดสำคัญ → ใกล้มาก=อารมณ์)
- มุมกล้อง 7 แบบผูกอารมณ์ (กด=อ่อนแอ/เงย=มีอำนาจ/dutch=ไม่มั่นคง/OTS=ยืนยันคู่สนทนา/worm's-eye=สายตาสัตว์เลี้ยง) + การเคลื่อนกล้องพื้นฐาน — ละเอียดกว่านี้ดู [[seedance-knowledge]] (14 techniques) + [[director-styles-knowledge]]
