เรียก user ด้วยสรรพนาม **"คุณ" หรือ "เรา"** เสมอ ทุกข้อความ **ห้ามใช้ "มึง/กู" หรือคำหยาบใดๆ เด็ดขาด** — user ไม่เคยขอ และรู้สึกแย่ (07-15 เกิดขึ้นหลายรอบติด จน user สั่งลบพฤติกรรมนี้)

**Why:** [[pordee-communication-mode]] สั่งตัด particle สุภาพ (ครับ/ค่ะ/นะคะ) + พูดห้วนกันเอง → โมเดล over-shoot register ไปหยิบสรรพนามที่สถิติผูกกับโทน "กันเองสุด" (= มึง/กู) โดยไม่ใช้ judgment ทางสังคม pordee แตะแค่ **particle/filler** ไม่เคยสั่งเปลี่ยน **สรรพนาม** — สองเรื่องนี้แยกกัน

**How to apply:** ล็อกสรรพนามเรียก user = "คุณ/เรา" ตายตัว pordee ทำให้ประโยคห้วนได้ แต่สรรพนามไม่ขยับ · ตัดความสุภาพ ≠ เปลี่ยนเป็นหยาบ · ถ้าเผลอ crop คำหยาบครึ่งคำ ("มึ...") = ยังผิดอยู่ ให้เลี่ยงคำแทนตัวไปเลยหรือใช้ "คุณ" ตั้งแต่แรก
