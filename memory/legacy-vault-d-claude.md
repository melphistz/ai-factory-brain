`D:\Claude` (เครื่อง Windows) เคยเป็น Obsidian vault + ระบบ "Claude เป็น Brain" สำหรับงาน AI video — **เกษียณแล้ว 2026-07-05** หลังความรู้ทั้งหมด merge เข้า `D:\ai-factory-brain\memory` (เวอร์ชัน vault เก่ากว่า repo ทุกไฟล์ ตรวจ hash แล้ว)

สิ่งที่ยังใช้อยู่ใน `D:\Claude`:
- `90-Assets/` — ที่พักไฟล์หนัก per-machine (reference images, generated video) — **ไม่เข้า git โดยตั้งใจ** · แต่ character sheet ไฟล์เล็กของโปรเจกต์ให้เก็บใน repo ที่ `projects/<ชื่อ>/assets/` แทน (sync ข้ามเครื่อง)
- `_archive-2026-07-05/` — สำเนาเก่าทั้งหมด (00-Knowledge, 10-Projects, 99-Templates, Home.md เดิม) เก็บกันเหนียว **อย่าแก้/อย่าอ่านเป็นความรู้**
- `Home.md` ใหม่ = ป้ายชี้ไป repo

memory ของ project dir นี้ (`~/.claude/projects/D--Claude/memory`) เป็น junction → repo memory แล้ว — เปิด claude จาก `D:\Claude` หรือ `D:\ai-factory-brain` ก็ได้สมองก้อนเดียวกัน (ของเก่าอยู่ `memory.bak-20260705`)

**How to apply:** งานความรู้/โปรเจกต์ทั้งหมด → ทำใน `D:\ai-factory-brain` · `D:\Claude` ใช้แค่เป็นที่วางไฟล์หนัก
