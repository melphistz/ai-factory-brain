# UGC Ad Structure — โครงสร้าง + teardown ตัวอย่างจริง

> โครงสร้าง UGC ad ที่ขายได้ + ถอดโครงตัวอย่างจริง. คู่กับ [[seedance-ugc-repository]] (วิธีเขียน prompt UGC) · [[ai-influencer-image-prompt]] (realism)

## 🦴 โครงมาตรฐาน (5-beat)
| ส่วน | t (15s) | หน้าที่ |
|---|---|---|
| **HOOK** | 0–3s | pattern interrupt หยุด scroll — bombshell/คำถาม/ของหล่น |
| **PROBLEM/VALUE** | 3–6s | ทำไมต้องสน — pain point หรือ stake (เงิน/เวลา/ผล) |
| **MECHANISM/PROOF** | 6–10s | กลไก + **โชว์** ไม่ใช่แค่บอก |
| **PAYOFF** | 10–13s | ผลลัพธ์ casual ไม่ hype |
| **SOCIAL PROOF + CTA** | 13–15s | คนอื่นทำแล้ว N คน → join/swipe/comment |

หลัก: no voiceover ขายตรง · เล่าเหมือน creator แชร์ความลับ · caption เน้นคำ key · ตัว ad ควรเป็น proof ของสิ่งที่ขาย

## 📋 Teardown #1 — "AI Video Skool" (AI-generated UGC, 18s, 9:16)
> output จริงของ skool.com/aivideoskool — convincing มาก ดูไม่ออกว่า AI

**Script (เรียงเวลา):**
| t | ฉาก | caption พูด |
|---|---|---|
| 0–3s | รถ เสื้อขาว selfie | "everything you're looking at is **AI generated**" |
| 3–6s | ห้องนอน cami | "businesses are paying **thousands** for them" |
| 6–9s | รถ hoodie ขับ | "...all of it... **single person** on..." |
| 9–12s | ครัว laptop | "**AI**... this kind of content" |
| 12–18s | end card skool app | "over **2,000 people** are already putting [out content]... be the one who kept up" |

**โครง:**
- **HOOK** = "ทุกอย่างที่เห็น = AI" → bombshell (สาวทั้งคลิปคือ AI)
- **STAKES** = "ธุรกิจจ่ายเป็นพัน" → = เงิน
- **MECHANISM** = "คนเดียว + AI ทำได้หมด"
- **SOCIAL PROOF + CTA** = end card 2.3k members → join Skool

**⭐ จุดอัจฉริยะ (เอาไปใช้):**
1. **ad = AI ทั้งคลิป → live demo ของสิ่งที่ขาย** (proof by being the product)
2. **scene variety (รถ/นอน/ครัว) = proof สด** ของเคลม "1 คนทำ content เยอะ" — โชว์ไม่ใช่บอก
3. **identity lock** หน้าเดียวข้าม 6+ ฉาก (ดู [[ai-character-identity-lock]])
4. caption เหลือง-ขาว เน้นคำ key (AI generated / thousands / 2,000) — ทำใน edit
5. no voiceover ขายตรง — UGC native, creator แชร์ความลับ
6. end card = screenshot app จริง + talking head มุมล่าง

**reusable pattern:** `Hook (it's all AI/X) → Stakes (people pay $$$) → Mechanism (1 person + tool) → Social proof (N members) → CTA (join)` — ใช้ขาย course/tool/skill ได้ทั่วไป

## 📋 Teardown #2 — "Never show your face / This woman is not real" (AI influencer, 37s)
> advertiser เดียวกับ #1 (AI Video Bootcamp) คนละ angle — storytime + low-ticket $9

**Script:** "okay so story — **this woman is not real**... made a smoothie... **all fake brands**... content on demand. someone asked if [real] — **I'm literally generated**. craziest part — accounts **with bigger followings** [ก็ AI]... second wild right — **it's 9 bucks**... **links below**"

**โครง:**
| ส่วน | t | |
|---|---|---|
| HOOK (storytime) | 0–3s | sticker "THIS WOMAN IS NOT REAL" + "okay so story" — curiosity |
| PROOF/DEMO | 3–12s | lifestyle (smoothie/skincare) + **"Reference Image" inset บนจอ** = โชว์ method สด (1 ref → หลายฉาก) |
| TWIST | 12–18s | "I'm literally generated" — เล่นกับ reveal |
| ESCALATION (FOMO) | 18–24s | "craziest part — บัญชี follower เยอะกว่าก็ AI" |
| OFFER + CTA | 24–37s | "**9 bucks**... links below" — low-ticket + CTA ตรง |

**ของใหม่ vs #1:**
- **storytime hook** ("okay so story") — curiosity ไม่ใช่ claim ตรง
- ⭐ **"Reference Image" inset** บนจอ — โชว์ method สด (transparent demo = educational hook)
- **price anchor $9 + "links below"** (low-ticket, vs #1 join community)
- **escalation beat** ("craziest part") ก่อน CTA
- auto-caption lowercase italic word-by-word

## 🔁 Pattern ร่วม (สูตร niche AI-influencer)
- ⭐ **"This is AI / not real" = hook formula** ของสายนี้ (หยุด scroll ด้วยความไม่น่าเชื่อ)
- **scene variety = proof สด** (โชว์ 1 คนทำหลายคลิป/ฉาก)
- **AI ขาย AI** — ad เป็น demo ของ product เอง (proof by being the product)
- no hard voiceover · เล่าเหมือน creator แชร์ความลับ · caption เน้นคำ key
- CTA: community (#1) หรือ low-ticket $ + links (#2)

## 📊 Campaign variant strategy (AI Video Bootcamp/Skool — เห็น 4 variant)
> insight สำคัญ: **advertiser เดียวรัน variant เยอะมาก** — สลับ model/scene/hook-execution บน **โครง script เดียว** = A/B test scale

| # | hook | model | opening scene | social proof / offer |
|---|---|---|---|---|
| 1 | "businesses paying $$$" | เอเชีย | รถ selfie | join community (2.3k) |
| 2 | "this woman is not real" | fitness/ตะวันออกกลาง | ห้องนอน storytime | $9 + links below |
| 3 | "this is 100% AI" | ลาติน | ตลาดนัดกลางคืน | (reveal) |
| 4 | "this woman is AI / end the debate" | บลอนด์ candid | skincare/bandana/coffee/gym | 18,000 learning |

| 5 | **surreal spectacle** (หัวหลุดบนเคาน์เตอร์ / แขนทะลุหน้าต่าง / หัวห้อย) | บรูเน็ต | คอนโด high-rise | thousands/decade |

### 🎭 2 hook archetype
| archetype | ขายอะไร | ตัวอย่าง |
|---|---|---|
| **realism-reveal** "this is AI / not real" | เนียนจนแยกไม่ออก | #1–4 |
| **surreal-spectacle** "look what AI can do" | ทำสิ่งเป็นไปไม่ได้ (หัวหลุด/แขนทะลุ/หัวห้อย) = WOW | #5 |
> archetype 2 ใช้ **จุดแข็ง Seedance** (physics/surreal/multi-subject — [[seedance-prompt-repository]]) เป็น spectacle hook แทน realism

**สูตรร่วม (ทุก variant):**
1. ⭐ hook = **"this is AI / not real"** sticker เหลือง + พูดเปิด
2. **scene variety 5-7 ฉาก** (lifestyle: รถ/นอน/ครัว/gym/skincare) = proof สด "1 คนทำได้เยอะ"
3. **AI ขาย AI** — ad = demo ของ product
4. social proof ตัวเลข (2.3k / 18,000) + CTA (community / $9 / links)
5. real product weave-in บางตัว (Onyx Coffee bag) — โชว์ว่าทำ brand content ได้

**กลยุทธ์:** ทำ **1 โครง script** → swap **model + scene + ตัวเลข + offer** → ยิง ad หลายตัว test ตัวไหน convert. **ทำซ้ำได้ด้วย identity-lock + scene variety** ([[ai-character-identity-lock]] + [[ai-influencer-image-prompt]])

## 🛠️ Workflow audit วิดีโอ (ffmpeg → frame read)
ตรวจ Seedance/UGC output โดยแตกเฟรมให้ Claude อ่าน (เห็นวิดีโอเล่นไม่ได้ แต่อ่านเฟรมได้):
```
ffmpeg -i video.mp4 -vf "fps=1/1.5,scale=540:-1" out/f_%02d.jpg
```
- fps=1/1.5 = 1 เฟรม/1.5 วิ · อ่านเฟรมไล่ → audit มือ/ขา/หน้า/morph + เก็บ caption = ถอด script
- ffprobe = metadata · ช่วง transition/fast = แตกถี่ขึ้น (fps=2) เช็ค morph

**Batch หลายคลิป (contact-sheet = 1 ภาพ/คลิป เร็วกว่าโยนทีละเฟรม):**
```bash
cd /path/to/Ads; OUT=./sheets; mkdir -p "$OUT"; i=0
for f in *.mp4; do i=$((i+1))
  dur=$(ffprobe -v error -show_entries format=duration -of csv=p=0 "$f")
  rate=$(python3 -c "print(max(0.1,12/$dur))")
  ffmpeg -y -loglevel error -i "$f" -vf "fps=${rate},scale=200:-1,tile=3x4" -frames:v 1 "$OUT/sheet_$(printf %02d $i).jpg"
done
```
- ⚠️ **image cap/session:** sheet ต้อง **<2000px ทุกด้าน** + ถ้า session โหลดรูปไปเยอะแล้ว (~50+) API บล็อกรูปใหม่ → ทำใน **session สด** (หลัง /clear) · scale=130-200 ปลอดภัย
- งานค้าง: โฟลเดอร์ `~/Desktop/Ads` มี 10 ad (แกะแล้ว 5 = #1-5 matrix · เหลือ ~5-8 ตัว — น่าจะ variant เดิม เช็คว่ามี angle ใหม่ไหม)
