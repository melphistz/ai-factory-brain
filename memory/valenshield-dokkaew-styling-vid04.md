> **REF ต้นแบบ: `/Volumes/WONYOUNG/Dokkeaw/ref/04.mp4`** = UNIQLO T-SHIRT "Workday Styling" (โมเดลชายในห้องแต่งตัว mid-century, ของลอยรอบตัว, super ชื่อสินค้า). Dokkaew = clone แนวนี้ แต่ผู้หญิง + ชุดพยาบาลลาเวนเดอร์.

## ⚠️ ข้อจำกัด → วิธีทำจริง (จากบทเรียน vid01-03)
- 🔑 **การเปลี่ยนชุด = HARD CUT ตอน edit** (ลุค N กดจิ้ม → cut → ลุค N+1 ว้าว) = **morph-safe, Seedance ไม่เปลี่ยนชุดกลางคลิป** (1 คลิป = 1 ชุด ตลอด). ปลอดภัยกว่า flash/dissolve, ตรงบทเรียน vid01-03

- **มือ = จุดเสี่ยง #1** เจน 5-6, จิ้มช้า-นิ่ง จุดเดียวคงที่. ของลอยไม่ render (AE)
